# Picsee Case Study

A static, responsive case study for **Picsee**, an 8-week self-initiated AI travel-planning concept. It is written to support an AI-first product or venture-studio application and focuses on product thinking, design hypotheses, desk research, design decisions, iteration, and individual contribution.

## Files

```
index.html   Main case-study page
style.css    Responsive visual system and layout
script.js    Navigation, scroll states, image placeholders, and lightbox
assets/      Project visuals and supporting documents
```

## Run locally

Open `index.html` directly in Chrome or Edge. No build step, server, framework, or backend is required.

## Replace visuals

Place replacement images in `assets/` using these filenames:

```
picsee-hero.png
planning-fragmentation.png
existing-user-journey.png
competitive-analysis.png
design-hypotheses.png
design-principles.png
user-flow.png
information-architecture.png
low-fidelity-wireframes.png
iteration-comparison.png
final-product-screens.png
ownership-and-next-steps.png
```

The page shows a labelled placeholder whenever an image is missing. Once a matching image is added, it appears automatically and can be opened in the lightbox. Use appropriately sized PNG, JPG, or WebP images; `object-fit: cover` keeps layouts stable.

## Edit copy

All visible case-study text is in `index.html`. Search for `[REPLACE:` before publishing. This project does not claim formal interviews, user testing, user quotes, or real research data; do not add invented metrics, quotes, or validated outcome claims.

## Deploy to GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Save. GitHub will show the public site URL after deployment.

## Public-link check

Before sharing, open the deployed URL in an incognito window. Check the LinkedIn, email, navigation, prototype-preview, and any replacement-image links. Add a real prototype URL only when it is public and intentional to share.
